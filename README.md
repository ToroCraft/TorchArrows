# Torch Arrows

A Minecraft mod that adds torch arrows - special arrows that place torches when they hit blocks and set living entities on fire.

**Version:** 1.21.8-1.0.0  
**Minecraft:** 1.21.8  
**NeoForge:** 21.8.39

## Features

- **Torch Arrows**: Craftable arrows that place torches when they hit blocks
- **Smart Placement**: Automatically places standing torches on top surfaces and wall torches on sides
- **Combat Ready**: Sets living entities (mobs, players, animals) on fire instead of placing torches
- **Cave Lighting**: Perfect for lighting up dark caves and areas while exploring

## Crafting Recipe

Craft torch arrows using torches and regular arrows in a crafting table.

## Development Environment Setup

```
git clone git@github.com:ToroCraft/TorchArrows.git
cd TorchArrows
./gradlew build
```

To run the development server:
```
./gradlew runServer
```

To run the development client:
```
./gradlew runClient
```
